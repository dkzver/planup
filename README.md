# PlanUp

Веб-редактор планировок помещений для дизайнеров. Рисуйте линии и стены, ставьте мебель из каталога, получайте объёмы работ в Excel.

**Live:** <https://dkzver.github.io/planup/>
**Редактор:** <https://dkzver.github.io/planup/#/editor>

Полное описание проекта, архитектуры и того, что сделано: [OPISANIE.md](./OPISANIE.md)

## Быстрый старт

```bash
npm ci
npm run dev
```

Нужен браузер с WebGL (Chrome, Edge, Firefox).

## Коротко о возможностях

- Главная без авторизации + 3D-редактор
- Стены, окна, двери, балкон — рисование и загрузка плана PDF/картинкой
- Каталог мебели с чекбоксами, историей расстановок и звёздами
- Объёмы работ (пол, стены, потолок, плинтус, двери, окна) в Excel
- Push/Pull, снап 10 см / оси 30 см, орбита как в SketchUp

Не является продуктом Trimble SketchUp.

## Деплой

- **Pages:** ветка `gh-pages` (`npx gh-pages -d dist`)
- **Render:** `render.yaml` (static site)

Подробности в [OPISANIE.md](./OPISANIE.md).
